# 设备申请与审批流程

> 文档编号：POL-IT-002　版本：v1.4　生效日期：2026-02-01
> 本文档为虚构企业内部流程，仅用于演示。

## 申请入口

所有设备申请统一通过 IT 服务台提交，不接受口头、即时消息或邮件直接申请。紧急情况可先电话通知 IT 值班，但事后必须在 1 个工作日内补交工单。

## 必填信息

提交申请时必须填写：

1. 申请人员工编号与部门；
2. 设备类别（笔记本电脑 / 显示器 / 扩展坞 / 手机）；
3. 使用场景与期望发放日期；
4. 是否需要特殊配置（内存、硬盘、操作系统）；
5. 直属主管员工编号。

缺少上述任一信息，IT 将退回申请并要求补充。

## 审批层级

| 设备类型 | 审批人 |
|---|---|
| 标准配置电脑 | 直属主管 |
| 超出标准配置 | 直属主管 + 部门负责人 + IT 负责人 |
| 显示器、扩展坞 | 直属主管 |
| 值班手机 | 部门负责人 + IT 负责人 |
| 单次申请 5 台以上 | 在上述基础上增加财务复核 |

审批通过后，申请进入 IT 发放队列；审批被拒绝的，工单关闭并记录原因。

## 时限

- IT 在收到完整申请后 1 个工作日内完成库存核对；
- 有库存的，2 个工作日内完成发放；
- 无库存的，1 个工作日内反馈预计到货时间并登记排队；
- 新员工入职场景优先处理，原则上入职当日完成。

## 紧急申请

仅限以下情形走紧急通道：生产事故处理、监管检查、重大客户交付。紧急申请仍需补全审批，IT 可先发放备用机，24 小时内补齐手续。

## 采购补充

库存低于安全水位（笔记本电脑 3 台、显示器 3 台、扩展坞 2 台）时，IT 负责人发起采购申请。采购到货后由 IT 统一入库并登记资产编号。

## 记录与审计

每次申请、审批、发放都要留下工单记录与操作人；资产系统状态必须与工单一致。审计抽查发现不一致的，按流程违规处理。
