# 电脑领用制度

> 文档编号：POL-IT-001　版本：v2.1　生效日期：2026-01-01
> 本文档为虚构企业「星尘科技（虚构）」的内部制度，仅用于演示。

## 适用范围

本制度适用于星尘科技（虚构）全体正式员工、实习生与外聘顾问。外包驻场人员领用设备需由对接部门负责人额外审批。

## 配置标准

公司按岗位序列配置标准电脑，超出标准配置需部门负责人与 IT 负责人双签：

| 岗位序列 | 标准配置 | 备注 |
|---|---|---|
| 研发 / 测试 / 算法 | ThinkPad T14 或 MacBook Air 13，16GB 内存起 | 可按项目申请 32GB |
| 产品 / 设计 | MacBook Air 13 或 ThinkPad X1 Carbon | 需外接显示器 |
| 职能（财务 / 人力 / 行政） | ThinkPad L14 | 默认不含独立显卡 |
| 客服 / 运营 | ThinkPad L14 或同档机型 | 值班岗位可申请值班手机 |

## 领用条件

1. 已完成入职手续并取得员工编号；
2. 设备申请已在 IT 服务台登记，且审批状态为「已通过」；
3. 领用人签署《设备领用确认单》，确认设备编号、配件与外观状态。

新员工入职的设备申请，应在入职前 3 个工作日内提交；IT 在入职当日完成发放与开机配置。

## 库存不足的处理

当所需机型库存为 0 时：

1. IT 在工单中登记「缺货排队」，并给出预计到货时间；
2. 可先用同档备用机临时发放，备用机同样需要领用登记；
3. 不允许以「先拿走再说」的方式绕过库存登记；
4. 采购补充由 IT 负责人发起，单次补充数量超过 5 台需财务复核预算。

## 领用流程

1. 申请人在 IT 服务台提交设备申请工单，填写岗位、机型、用途与期望发放日期；
2. 直属主管审批；
3. IT 核对库存与配置标准；
4. 申请人到 IT 仓库领取，核对设备编号后签收；
5. IT 在资产系统中把设备状态改为「使用中」并登记领用人。

任何环节都不得跳过工单直接发放设备；制度以工单记录与资产系统状态为准。

## 归还、变更与离职

- 员工转岗需要更换机型的，先归还旧设备再领用新设备；
- 离职员工应在最后一个工作日前归还电脑、扩展坞与值班手机；
- 设备损坏或丢失，需在 1 个工作日内提交工单说明，按《信息安全与数据分级》处理数据清除；
- 归还设备经 IT 检测后状态改为「在库」或「维修」，不得直接再次发放未检测设备。

## 违规处理

未登记领用、私自转借、擅自拆机的，IT 有权收回设备并通报直属主管；造成数据泄露的，按信息安全制度处理。
