# 设备申请与审批流程（2025 旧版）

> 文档编号：POL-IT-002-2025　版本：v1.0　状态：**已废止（2026-02-01 起由 v1.4 替代）**
> 本文档仅用于演示"版本冲突"，不代表现行制度。

## 审批层级（旧版）

| 设备类型 | 审批人 |
|---|---|
| 标准配置电脑 | 直属主管 |
| 显示器、扩展坞 | **部门负责人** |
| 值班手机 | 部门负责人 + IT 负责人 |
| 单次申请 3 台以上 | 财务复核 |

## 时限（旧版）

- 新员工设备申请在**入职后 5 个工作日内**提交即可；
- IT 在收到申请后 3 个工作日内完成发放。

## 说明

2026-02-01 起，上述条款已被《设备申请与审批流程》v1.4 替代：显示器/扩展坞改为直属主管审批，
新员工申请需在入职前 3 个工作日内提交。旧版仅作历史存档，不得作为当前执行依据。
